# AWS CardDemo sample corpus

This offline Cobolens sample contains the COBOL, copybook, and JCL files under
`app/` from
[`aws-samples/aws-mainframe-modernization-carddemo`](https://github.com/aws-samples/aws-mainframe-modernization-carddemo)
at commit `59cc6c2fd7ebd7ef7925cad552a01a4b8b6e4d5e`.

Data files, archives, generated binaries, BMS, assembler, and deployment
material are intentionally excluded. Included source files are unchanged.
