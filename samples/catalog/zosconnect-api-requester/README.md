# z/OS Connect COBOL API Requester sample corpus

This offline Cobolens sample contains the COBOL, copybook, and JCL files from
[`zosconnect/zosconnect-sample-cobol-apirequester`](https://github.com/zosconnect/zosconnect-sample-cobol-apirequester)
at commit `d4fa75e7c57a99b84efabf1b35d2eb5dc8724485`.

Only source types analyzed by Cobolens are included. The files are otherwise
unchanged. Upstream license: Apache-2.0; see `LICENSE` in this directory.
